# Projeto de estudo

O caderno de um projeto de aprendizado: construir, do zero e por partes, um **Banco** (com PIX entre dois bancos), uma **Nuvem** (deploy por `git push`, serviços gerenciados, orquestração) e uma **Escola** (cursos, juiz de código, vídeo e aula ao vivo), estudando cada conceito no momento em que ele é necessário.

Aqui fica **o processo**, não o código. O código de cada sistema mora no repositório dele.

| Arquivo | O que é |
|---|---|
| [ROADMAP.md](ROADMAP.md) | Os itens, em ordem, com o que estudar e o critério de pronto |
| [METODOLOGIA.md](METODOLOGIA.md) | Como cada item é feito: problema → estudo → checagem → caminhos → decisão → plano → execução → fechamento |
| [ESTADO.md](ESTADO.md) | Onde o projeto está agora |
| [DECISOES.md](DECISOES.md) | As decisões tomadas, uma por linha |
| [REPERTORIO.md](REPERTORIO.md) | O que já foi feito e com que autonomia |
| [itens/](itens/) | O caderno de cada item |
| [CLAUDE.md](CLAUDE.md) e [PROMPT.md](PROMPT.md) | As instruções para a IA que acompanha o estudo |

Os livros de base são *Fundamentos da Arquitetura de Software* (Richards e Ford), *Projetando Aplicações com Uso Intensivo de Dados* (Kleppmann e Riccomini) e *Aprenda Domain-Driven Design* (Khononov), lidos capítulo a capítulo ao longo do roadmap.
